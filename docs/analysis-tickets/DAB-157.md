## Context

`RotatingFileHandler` names its backups `<file>.1`, `<file>.2`, and so on. The glob `*.log` does
**not** match `bot.log.1`.

By construction the rotated files hold the *older* history — including full user message content,
uploaded-file content, and unredacted exception text, all of which reach the log today
(`DAB-154`, `DAB-155`). A solo operator who `git add -A`s their own bot repo and pushes it to
GitHub publishes their guild's conversations.

One line of `.gitignore` fixes it.
