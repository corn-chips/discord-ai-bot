### Prioritization Method

Priority score = `(impact if unfixed x frequency of encounter) / fix effort`.

- Impact: Low = 1, Medium = 2, High = 3, Critical = 4.
- Frequency: Rare = 1, Occasional = 2, Common = 3, Continuous = 4.
